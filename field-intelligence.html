City Affinity Matrix
How cultural metadata fields multiply exhibition performance in each city. Multipliers apply to base exhibition value.
How it works: When a painting travels to a city, the system checks its cultural fields (movement, nationality, culture, period, dynasty) against each city's affinity table. Matching fields apply their multiplier — multiple matches stack multiplicatively. A French Impressionist painting in Paris can achieve 4.0× base value. Fields that drive this: movement, artistNationality, culture, period, dynasty, origin, productionPlaces.

Database Coverage Heatmap
How many fields each database provides per category. Darker = richer coverage.

Reading the heatmap: Numbers show field count per category from each database. Rijks leads on Physical (materials, techniques, colors). AIC leads on Thematic (subjects, classifications, styles) and has the only publication history. Harvard is uniquely strong on Demand (pageViews, rank, publicationCount). Cleveland provides unique narrative fields (funFact, wallDescription). Wikidata bridges cross-museum identity. Met is the broadest single source.
